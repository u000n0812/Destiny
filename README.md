# 사주 명리 감정서 대시보드

사주 해석은 **사람이 직접** 하고, 그 결과를 타이핑하면 곧바로 의뢰인에게 건넬 수 있는
A4 3매 감정서가 만들어집니다. `index.html` 파일 하나로 동작하며 설치·서버·인터넷이 필요 없습니다.

## 쓰는 법

`index.html`을 브라우저로 열고 빈칸을 채우면 됩니다.

| 버튼 | 하는 일 |
|---|---|
| **작성 / 미리보기** | 입력칸 배경을 켜고 끕니다. 미리보기가 의뢰인이 받는 모습입니다 |
| **예시 채우기** | 가상의 예시로 전체를 채워 봅니다 (레이아웃 확인용) |
| **JSON 저장 / 불러오기** | 의뢰인별로 파일 보관. `Ctrl/Cmd+S`도 같은 기능 |
| **인쇄 · PDF** | 자동으로 미리보기로 바꾼 뒤 인쇄창을 엽니다. 대상을 *PDF로 저장*으로 두면 3쪽 PDF가 나옵니다 |
| **비우기** | 전부 지우고 새 의뢰인 시작 |

입력하는 대로 브라우저에 자동 저장되므로 창을 닫아도 이어서 작업할 수 있습니다.
저장 위치는 그 브라우저 안이며, 다른 기기로 옮기려면 JSON으로 내보내십시오.

**분량이 넘치면** 해당 쪽 우측 하단에 `내용이 지면을 넘칩니다` 표시가 뜹니다.
각 입력칸의 기본 높이가 곧 그 항목에 쓸 수 있는 분량의 기준입니다.

### 손이 덜 가도록 해 둔 것

- **오행 자동 집계** — 천간·지지 여덟 글자를 넣으면 오행을 판별해 글자 색과 분포 막대에 반영합니다.
  한자(`甲`)와 한글(`갑`) 모두 인식합니다. 지장간까지 반영해 직접 세고 싶으면 숫자를 고쳐 쓰면 되고,
  그때부터는 자동 집계가 멈춥니다(`비우기`로 되돌림).
- **없는 오행 표시** — 빠진 오행이 있으면 해당 막대에 붉은 테두리와 `무(無)오행` 표기가 붙습니다.
- **세운 연도** — 감정일 연도에서 당해년·익년을 자동으로 채웁니다.
- **길흉 색** — 대운표에서 대길/길·평·흉/대흉을 고르면 색과 글자가 함께 바뀝니다.
- **형충회합·신살·키워드** — 쉼표로 구분해 적으면 칩으로 정리되고, 충·형·살이 든 항목은 붉게 표시됩니다.

## 3매에 담은 항목과 그 근거

전통 감명(鑑命) 순서 — 명식을 세우고 → 월지 기준으로 격국을 잡고 → 오행의 강약으로 신강·신약을
가린 뒤 → 용신·기신을 정하고 → 십성·신살·형충회합을 살펴 → 대운·세운에 대조해 종합한다 —
를 그대로 쪽 순서로 옮겼습니다.

**1면 · 명식과 구조** — 의뢰인 정보(진태양시 보정 포함) · 사주 명식(천간/지지, 천간·지지 십성,
지장간, 십이운성) · 형충회합 · 신살 · 오행 분포 · 강약 판단(득령·득지·득세·한난조습) ·
격국과 용신(일간, 격국, 용신·희신, 기신·구신) · 총평

**2면 · 성향과 삶의 영역** — 십성 세력(비겁·식상·재성·관성·인성) · 기질 키워드 ·
성격과 내면 · 대인관계와 인연 · 직업과 적성 · 재물의 흐름 · 건강

**3면 · 운의 흐름과 제언** — 대운 8구간(나이·간지·십성·길흉·요약) · 세운(당해년·익년) ·
개운(보완 오행·색·방위·숫자·계절) · 종합 제언 · 낙관과 면책 문구

## 색에 관한 메모

오행 색(목=청, 화=적, 토=황, 금=백, 수=흑)은 전통적으로 정해져 있지만 흰색과 검은색은
지면 위 막대 색으로 쓸 수 없어, 각 오행을 알아볼 수 있으면서 서로 구별되는 값으로 옮겼습니다.
금(백)은 은빛 계열이 회색으로 뭉개지고 수(흑)와 겹쳐, 자색 쪽으로 옮겨 분리했습니다.

밝은 화면과 인쇄에 쓰는 값은 명도·채도·정상시야 구별·대비 검사를 모두 통과합니다.
어두운 화면에서는 화(적)와 토(황)가 적록색약에서 가까워지는데, 이는 두 색이 전통적으로 고정된
탓에 피할 수 없는 부분입니다. 대신 모든 막대에 한자·한글·개수·비율이 항상 함께 적혀 있어
색만으로 구분해야 하는 상황은 생기지 않습니다.

## 한계

- 만세력 계산은 하지 않습니다. 명식·대운수·진태양시는 감정인이 직접 세워 입력합니다.
- 해석 문장을 생성하지 않습니다. 판단과 문장은 전적으로 감정인의 몫입니다.
- 한글 글꼴은 기기에 설치된 것(Pretendard·맑은 고딕·애플 SD 산돌고딕네오, 제목은 명조·바탕)을
  씁니다. 기기에 따라 글자 폭이 달라져 분량이 밀릴 수 있으니, 인쇄 전 넘침 표시를 확인하십시오.
